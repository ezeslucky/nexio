# Security Policy

## Supported Versions

We recommend users to always use the latest version of Nexio. Security updates will be provided for the current active releases:

| Version         | Supported          |
| --------------- | ------------------ |
| 1.0.x (stable)  | :white_check_mark: |
| 0.27.x          | :white_check_mark: |
| < 0.27.x        | :x:                |

## Reporting a Vulnerability

We welcome you to report security vulnerabilities directly on [GitHub](https://github.com/ezeslucky/nexio/security), **we encourage you to submit the relevant information directly via GitHub Advisory/Security**.

We expect your report to contain at least the following for us to evaluate and reproduce:

1. Operating system, platform, and Nexio version, for example:
   - macOS arm64 v1.0.0
   - Windows x64 v1.0.0
   - Nexio Web (http://localhost:8080)

2. A set of reproduction steps (video or screenshot) demonstrating the vulnerability, including timestamps and software versions.

3. Your classification or severity analysis of the vulnerability (optional).

Since we are an open source project, we also welcome you to provide corresponding fix PRs.

Due to limited resources, we do not accept and will not review automated or AI-generated security scanner spam without a verified proof of concept.

If the vulnerability is caused by an upstream dependency we rely on, we encourage you to submit a security report to the corresponding library as well.
